# Addis Eats Next.js Route Tree

This project contains the complete routing structure for the Addis Eats application, demonstrating Next.js App Router conventions.

## Routes and Files

- **`/` (Home)**: Generated by `app/page.js`
- **`/menu`**: Generated by `app/menu/page.js`
- **`/menu/[id]`**: Generated by `app/menu/[id]/page.js` (Dynamic routing via props)
- **`/cart`**: Generated by `app/cart/page.js`
- **`/checkout`**: Generated by `app/checkout/page.js`

## Special Files

- **`app/menu/loading.js`**: Displays a loading boundary for the menu segment.
- **`app/menu/error.js`**: Client component catching runtime errors in the menu segment.
- **`app/not-found.js`**: Displays when a non-existent URL is hit or `notFound()` is invoked.
- **`app/menu/DishList.jsx` & `app/menu/CategoryBar.jsx`**: Colocated components that do not act as routes.
