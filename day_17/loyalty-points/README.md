# TeleBirr Shop Loyalty Points Module

## Description

This project implements a loyalty-points system for a TeleBirr shop using JavaScript closures and higher-order functions.

The module allows a customer to:

- Earn loyalty points
- Redeem loyalty points
- Check their current points balance
- Use different earning rules
