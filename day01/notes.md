# Day 1 Notes

## Five Terminal Commands

1. pwd - Shows the current directory.
2. ls - Lists files and folders.
3. cd - Changes directories.
4. mkdir - Creates a new folder.
5. touch - Creates an empty file.

## Three Git Commands

1. git status - Shows repository status.
2. git add . - Stages changes.
3. git commit -m "message" - Saves a snapshot of staged changes.
