# Addis Eats Next.js Route Tree & Rendering Boundary

This repository contains the routing structure and strict Server/Client boundaries for the Addis Eats application.

## Routes and Files

- **`/` (Home)**: Generated by `app/page.js`
- **`/menu`**: Generated by `app/menu/page.js`
- **`/menu/[id]`**: Generated by `app/menu/[id]/page.js` (Dynamic routing via props)
- **`/cart`**: Generated by `app/cart/page.js`
- **`/checkout`**: Generated by `app/checkout/page.js`

## First Load JS for `/menu` (Day 38 Boundary Sorting)

- **Before (Day 37):** 85 kB
- **After (Day 38):** 81 kB

**Difference Explanation:** By pushing the `"use client"` directive down from the parent `menu/layout.js` into a smaller `Counter.jsx` component, and by using `children` to pass server-rendered components into client shells, we reduced the amount of JavaScript sent to the browser.
