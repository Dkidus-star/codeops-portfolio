# Addis Market

## Project Description

Addis Market is an interactive shopping list application built using HTML, CSS, and vanilla JavaScript.

The application allows a user to add shopping items with their ETB prices, mark items as bought, delete items, and see a live running total.

This project is the foundation for the Week-2 project and will be extended later with browser storage and a live API.

---

## Features

- Add a shopping item
- Enter an ETB price
- Validate the form
- Prevent page reload when submitting
- Dynamically create shopping list rows
- Mark an item as bought
- Delete an item
- Calculate a live ETB total
- Use event delegation
- Responsive design

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- DOM Events
- Event Delegation

No JavaScript framework is used.
