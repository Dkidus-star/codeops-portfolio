# TeleBirr Tip & Split Calculator

## Description

This is a simple JavaScript calculator that calculates a restaurant
bill, applies a tiered tip, calculates the total, and splits the
total between members of a party.

## Rules

- If the bill is over 300 ETB, the tip is 10%.
- If the bill is 300 ETB or less, the tip is 5%.
- The total is the original bill plus the tip.
- The total is divided by the party size.

## Example

Bill:

500 ETB

Party size:

4 people

Tip:

10%

Tip amount:

50 ETB

Total:

550 ETB

Amount per person:

137.50 ETB

## How to Run

Make sure Node.js is installed.

Run:

```bash
node tip.js
```
